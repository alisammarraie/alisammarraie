# Building tools for infrastructure, urban mobility and GIS

I turn transport and spatial planning questions into interactive tools that make assumptions visible and scenarios easier to explore.

## Featured projects

### [LoopLab · Pod Transit Simulator](https://github.com/alisammarraie/looplab)

Explore a pod transit network: same-destination pooling, FIFO station queues, road signals and scenario comparisons. Import KMZ, KML or GeoJSON to reuse the demonstrator with another network.

[Try the demo →](https://alisammarraie.github.io/looplab/src/)

### [WalkingIndex · Walking Accessibility Explorer](https://github.com/alisammarraie/walkingindex)

See what people can reach along a walking network. Change the time budget, close a bridge or exclude flagged paths, then compare access to everyday destinations.

[Try the demo →](https://alisammarraie.github.io/walkingindex/)

## My approach

- Make the operating logic and data assumptions visible.
- Use fictional examples so tools can be explored without project data.
- Separate analysis from presentation and test the underlying calculations.
- Document limitations alongside results.

**Areas of interest:** transport operations · spatial networks · accessibility · scenario planning · browser-based GIS.

These are independent working prototypes, developed with AI assistance. Their repositories explain methods, tests and limits.
